# 💬 Chat Application – Firebase + React

A real-time chat application built using React and Firebase.  
Users can authenticate and send/receive messages instantly using Firestore database.

---

## 🚀 Features

- 🔐 Firebase Authentication (Login / Signup)
- 💬 Real-time messaging
- 🕒 Message timestamps
- 📱 Responsive UI
- 🔥 Firestore Database integration

---

## 🛠 Tech Stack

- React (Create React App)
- Firebase Authentication
- Cloud Firestore
- HTML5
- CSS3
- JavaScript (ES6)
